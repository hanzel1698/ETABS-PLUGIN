# Test fixture: minimal ETABS model

ETABS' `.edb` model file is a proprietary binary format with no public
writer, so it can't be generated by a script and isn't checked into this
repository. Build it directly in ETABS instead — it takes a few minutes.

## Steps

1. **File > New Model.** When prompted to use settings from a previous
   model, choose **No**.
2. In the **New Model Quick Templates** dialog, choose the **Grid Only**
   template and set:
   - **Number of Stories**: `3`
   - **Typical Story Height**: any value, e.g. `12 ft` / `3.5 m`
   - **Bottom Story Height**: any value, e.g. `12 ft` / `3.5 m`
   - **Number of Grid Lines in X direction**: `2`
   - **Number of Grid Lines in Y direction**: `2`
   - **Spacing**: any value, e.g. `20 ft` / `6 m` (both directions)
   - Click **OK**.

   **Grid Only means grid only** — this creates the 1x1 bay grid and 3
   stories (default names Story1/Story2/Story3) but draws **no** columns
   or beams. Everything below is drawn by hand.
3. **Rename the stories** to match the fixture spec: **Edit > Edit Story
   Data > Edit Story** (or double-click a story label in an elevation
   view), and rename, bottom to top:
   - `Story1` → `G`
   - `Story2` → `L1`
   - `Story3` → `L2`
4. **Draw the 4 columns**, replicated to every story in one pass:
   - Open a **3D view** (or the bottom story's plan view).
   - **Draw > Draw Columns/Draw Column Objects** (or the column tool on
     the toolbar).
   - In the drawing options/side bar, set **Similar Stories** (or
     **Property/Story options**) to **All Stories** — this replicates
     each object you draw to every story instead of just the one you're
     drawing on.
   - Click each of the 4 grid intersections to place a column there.
   - Result: 4 columns × 3 stories = **12 column frame objects**. Right-
     click a column, or switch to a 3D view, to confirm it exists on
     G, L1, and L2.
5. **Draw 2 beams per floor**, also replicated to every story:
   - Switch to **Draw > Draw Beam/Reframe Objects**.
   - Confirm **Similar Stories** is still set to **All Stories**.
   - In the bottom story's plan view, draw 2 beams connecting grid
     intersections (e.g. the two beams along one pair of opposite edges
     of the single bay — your choice, since the spec just calls for 2
     per floor).
   - Result: 2 beams × 3 stories = **6 beam frame objects**.
   - If **Similar Stories** isn't available for beams in your ETABS
     version, repeat the same 2 beams manually in each of the G, L1,
     L2 plan views instead.
6. Switch to a **3D view** and eyeball it: you should see a single 1x1
   bay repeated over 3 levels, with 4 columns and 2 beams per level.
7. **File > Save As**, save as `test-model/StoryFrameLoggerFixture.edb`
   in this repository (or wherever is convenient) — the file is binary
   and safe to add to git if you want it versioned alongside the plugin.

## Expected plugin output

Running the plugin (see `../README.md`) against this fixture should log:

```
Stories (3):
  - L2
  - L1
  - G

Total frame objects: 18
  Columns: 12
  Beams:   6
```

Story order and exact column/beam counts depend on how you draw the
model — if you only add beams at 2 of the 3 levels, adjust the expected
beam/total counts accordingly (2 per floor you actually drew).
